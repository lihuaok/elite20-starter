1. AI 调用架构设计

1.1 整体架构

系统采用分层架构设计，将 AI 调用逻辑与 UI 展示分离，支持多服务提供商的灵活切换。

AI 调用架构图
用户输入层 → 代码输入、语言选择、API Key 配置
服务检测层 → 自动检测或手动选择 AI 服务
请求构造层 → Prompt 生成、参数配置、请求头设置
API 调用层 → 异步请求、超时处理、错误捕获
响应解析层 → JSON 解析、结果提取、异常处理
结果展示层 → Markdown 渲染、代码高亮、评分展示

1.2 核心模块划分

  • AI_SERVICES：多服务配置对象
  • detectService()：服务检测函数
  • callAI()：核心 API 调用函数
  • getDefaultAnalysis()：本地分析引擎
  • getHelp()：主入口函数

4. API 调用实现

4.1 核心调用流程

POST https://api.siliconflow.cn/v1/chat/completions

4.2 异步调用实现

async function callAI(code, language, apiKey) { const fullPrompt = `作为一名专业的编程辅导老师...`; const serviceType = detectService(apiKey); const service = AI_SERVICES[serviceType]; const cleanApiKey = sanitizeApiKey(apiKey); if (!isValidAscii(cleanApiKey)) { return { success: false, error: 'API Key 包含非法字符' }; } try { const controller = new AbortController(); const timeoutId = setTimeout(() => controller.abort(), 30000); const response = await fetch(service.url, { method: 'POST', headers: service.getHeaders(cleanApiKey), body: JSON.stringify(service.getBody(fullPrompt)), signal: controller.signal }); clearTimeout(timeoutId); if (!response.ok) { const errorText = await response.text(); throw new Error(`API 请求失败: ${response.status}`); } const data = await response.json(); return { success: true, result: service.parseResponse(data), service: service.name }; } catch (error) { return { success: false, error: error.message, service: service.name }; } }

5. 响应解析设计

{ "choices": [ { "message": { "role": "assistant", "content": "辅导报告内容（Markdown格式）" } } ], "usage": { "prompt_tokens": 150, "completion_tokens": 850 } }

5.2 错误处理策略

错误类型处理方式
认证失败 (401)提示 API Key 无效
模型不存在 (400)提示检查模型名称
请求超时提示超时并降级
网络错误提示检查网络连接

7. 降级机制设计

7.1 降级触发条件

  • API Key 为空或无效
  • AI 服务调用失败
  • 网络连接超时
  • CORS 跨域错误
降级机制优势：
  • 确保服务可用性
  • 提供基础分析能力
  • 减少 API 调用成本

8. 安全与性能优化

8.1 API Key 安全保护

  • 使用 type="password" 隐藏输入
  • 过滤非法字符和控制字符
  • 使用 HTTPS 传输
  • 本地缓存，不发送到服务器

8.2 性能优化策略

优化项实现方式
请求超时30秒超时自动取消
响应缓存会话级别缓存
延迟加载defer 属性加载脚本
