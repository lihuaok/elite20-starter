2. API Key 安全处理函数

这组函数用于清理和验证用户输入的 API Key，防止安全漏洞和字符编码问题。

2.1 isValidAscii() - ASCII 字符验证

1194 function isValidAscii(str) {
1195 for (let i = 0; i < str.length; i++) {
1196 if (str.charCodeAt(i) > 127) {
1197 return false;
1198 }
1199 }
1200 return true;
1201 }
功能说明：遍历字符串中的每个字符，检查其 ASCII 码是否超过 127。如果包含非 ASCII 字符（如中文、特殊符号等），返回 false。这可以防止复制粘贴时带入的隐藏字符或特殊字符导致请求失败。

2.2 sanitizeApiKey() - API Key 清理

1203 function sanitizeApiKey(apiKey) {
1204 if (!apiKey) return '';
1205 let sanitized = apiKey.trim();
1206 sanitized = sanitized.replace(/[\u0000-\u001F\u007F-\uFFFF]/g, '');
1207 return sanitized;
1208 }
清理步骤：
  1. 检查 API Key 是否为空，为空则返回空字符串
  2. 使用 trim() 去除首尾空格
  3. 使用正则表达式移除控制字符（\u0000-\u001F）和非 ASCII 字符（\u007F-\uFFFF）

4. 超时处理函数 (timeoutPromise)

为异步操作添加超时机制，防止请求无限等待。

1237 function timeoutPromise(promise, ms) {
1238 return new Promise((resolve, reject) => {
1239 const timer = setTimeout(() => {
1240 reject(new Error(`请求超时（${ms/1000}秒）`));
1241 }, ms);
1242 promise.then(
1243 (result) => {
1244 clearTimeout(timer);
1245 resolve(result);
1246 },
1247 (err) => {
1248 clearTimeout(timer);
1249 reject(err);
1250 }
1251 );
1252 });
1253 }
设计要点：
  • 包装传入的 Promise，添加超时定时器
  • 如果在指定时间（ms）内 Promise 未完成，自动 reject 并抛出超时错误
  • 如果 Promise 成功完成或失败，都会清除定时器，避免内存泄漏

8. 代码安全性

安全设计要点：
  • API Key 保护：使用 type="password" 隐藏输入，不存储到服务器
  • 输入验证：过滤非法字符和控制字符
  • HTTPS 传输：确保数据传输加密
  • 错误处理：详细但安全的错误信息，不泄露敏感数据
