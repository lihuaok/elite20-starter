2. AI 调用流程图

从用户输入到结果展示的完整调用流程，展示 getHelp() 函数的执行路径。

用户输入代码和 API Key

从 UI 获取代码内容、编程语言选择、API Key

服务类型检测

调用 detectService() 自动识别或使用用户选择的服务

构造完整 Prompt

将代码和评分标准组合成完整的提示词

发送 HTTP 请求

调用 fetch() 发送 POST 请求到 AI 服务

处理响应

解析 JSON 响应，提取 AI 返回的辅导报告

Markdown 渲染

使用 marked.js 将 Markdown 转换为 HTML

显示结果

将解析后的内容显示到页面，应用状态样式

用户是否手动选择服务？

读取 serviceType 下拉框的值

根据 API Key 格式判断服务

API Key 格式检测
sk- 开头且长度 > 50 → 硅基流动
